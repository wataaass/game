# LANTERNFALL — 灯火の底

ランタンの灯りで闇を払いながら地下へ降りていく、見下ろし型のアクションローグライクです。外部ライブラリも画像も音声ファイルも使わず、絵・音・地形のすべてを実行時にコードで生成します。

## 使い方
- **すぐ遊ぶ**: `dist/lanternfall.html` をブラウザで開く（単一ファイル。サーバー不要）
- **開発用に起動**: `npm start` → http://localhost:8080
- 必要なもの: WebGL2 対応のブラウザ。開発には Node.js 22 以降（npm パッケージは不要）

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印 |
| 照準・火花 | マウス・左クリック（押しっぱなしで連射） |
| ダッシュ（無敵あり） | Space / 右クリック |
| 階段を降りる | E |
| 強化を選ぶ | 1 / 2 / 3 |
| ポーズ / 消音 | Esc / M |
| リプレイ・デモの速度 | Tab |

### 遊び方
- 油は常に減り、減るほど灯りが狭くなる。尽きると闇から「影」が湧く。敵を倒す・部屋を制圧する・祠に触れると補給できる
- 部屋に入ると扉が閉まり、敵を全滅させると松明が灯る。消えた松明は近づけば火を移せる
- 残り火（経験値）が満ちると3択の強化。「延焼＋燃え移り」「貫通＋走る稲火」のように重ねると化ける
- 5層の主「灯らぬもの」は松明を消してくる。松明が消えているほど硬いので、火を戻しながら戦う
- タイトルでシードを入れると同じダンジョンを再現できる。死ぬと直前のプレイがリプレイとして残る

### 確認コマンド
- `npm run check` — lint・テスト・ビルドをまとめて実行
- `npm run balance -- 30` — bot による難易度の集計

## 使っている技術
- **決定的シミュレーション**（`src/sim`）: 1/60 秒固定刻み。種と入力列だけで全状態が決まるので、リプレイは入力（1ティック6バイト）の再生で済み、終了時の状態ハッシュが記録と一致するかを検証できる
- **ダンジョン生成**（`src/sim/dungeon.js`）: 間隔つきの部屋配置 → 最小全域木＋ループ → 曲がり角にコストを置いた A* で幅2の通路 → セルオートマトンなどで部屋を変形 → 到達不能な床の除去
- **敵 AI**（`src/sim/enemies.js`）: プレイヤーからの距離場を全員で共有する経路探索、見通しがあるときの包囲、偏差射撃、同時攻撃数の制限、3段階のボス
- **自動プレイ bot**（`src/sim/bot.js`）: 16方向の候補ごとに少し先の弾と敵の位置を予測して採点する。デモ表示と難易度の集計に使う
- **描画**（`src/render`）: WebGL2 を直接使う自作レンダラ。可視ポリゴンによる影つきライト、スプライトのインスタンス描画、HDR のブルーム、低解像度のピクセルアートをにじませずに拡大する合成
- **スプライト生成**（`src/render/atlas.js`）: 陰影つき楕円とディザで、キャラクターやタイルを起動時に1ピクセルずつ描く
- **音**（`src/audio/audio.js`）: Web Audio API だけで鳴らすチップチューン。パルス波2声＋三角波ベース＋ノイズドラムの4声で、層ごとの探索曲5つ・戦闘・ボス・タイトルの8曲とジングルを譜面データとして持ち、小節の頭で切り替える。効果音は約30種類を重ね合わせで合成する
- **ツール**（`tools/`）: 依存なしの lint・単一ファイル化バンドラ・開発サーバー

## 設計上の判断
- **依存ゼロ**: 何をどこまで自分で作れるかを見せるため。ビルド工程もなく、配布物は HTML 1枚
- **シミュレーションを DOM から切り離す**: Node 上で 25 分ぶんのプレイを約 0.5 秒で回せる。これでテスト・リプレイ・バランス集計がすべて成り立つ
- **難易度は数字で決める**: 腕前を変えた bot のクリア率を見て敵の数値を調整した（反応の速い bot で約9割、遅い bot で約1割）
- **灯りをルールにする**: 影の計算を見た目だけで終わらせず、油・松明・「影」の敵・ボスの硬さに結びつけた
